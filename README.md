**MachineFlows** is a lightweight Java package designed to model, simulate, and verify
whether a complex production circuit or manufacturing chain is self-sustaining in *Factorio*-like automation games.

**Network Modeling:** Represent machines, recipes, and resources as a dynamic production network.
**Self-Sustainability Verification:** Calculate steady-state item flows to mathematically prove if your factory loop
can run indefinitely without external resource injections.
